# 🔭 Opportunity Radar｜机会雷达

> **在机会变得人尽皆知之前，找到“你比别人更有机会赢”的生意。**

这是一个面向**从职场走向所有权**的人群的证据驱动型机会发现系统：产业 B2B 销售、外贸与跨境运营、工业技术与售后、采购与供应链、懂业务又会 AI 的行业操盘手、增长与商业化人才、创作者、工程师、商人和小团队。

**最新版：v8.1** · [English](README.md)

```text
Human Capital → Cash Flow → Owned Capital
人力资本 → 现金流 → 自有资产
```

一般的机会分析经常问：

> 哪个行业增长最快？

Opportunity Radar 追问的是：

> **到底发生了什么变化？什么职业天然站在变化附近？谁真正付钱？利润最后沉淀在哪里？证据到底够不够？窗口是不是还开着？这个具体的人能不能低成本进去，并把个人能力最终变成自己的资产？**

# 30 秒理解这套框架

一个行业很大，**不代表适合你创业**。

一个市场没那么大，也可能改变一个人的财富结构，只要它同时具备：

- 底层需求真实而持续；
- 某种结构变化打开新的进入窗口；
- 你原本积累的技能、客户、供应商、地域、信誉或隐性知识突然升值；
- 有明确付款人和预算；
- 证据强度配得上你准备下注的大小；
- 第一笔商业验证足够便宜、可逆；
- 成功后能从“卖自己的时间”继续沉淀为流程、数据、软件、产品、品牌、渠道、网络或股权。

真正的分析单位不是“行业”，而是：

```text
人 × 变化 × 证据 × 付款人 × 权力 × 所有权 × 时机
```

# 整体一步一步怎么推出来？

```text
1. 结构性需求
        ↓
2. 为什么偏偏是现在？——结构变化 / Power Redistribution
        ↓
3. 哪些职业天然更容易从职场迁移到创业？
        ↓
4. 年轻人 / 校园 / 招聘 / 买方行为等领先信号
        ↓
5. 真实客户付款
        ↓
6. 资本、供应链、标准和制度开始形成
        ↓
7. 毛利、复购、CAC、现金流等经济质量审判
        ↓
8. Power Pool：行业最后谁真正把利润留下来？
        ↓
9. 这个具体的人能不能进去？
        ↓
10. Evidence Coverage + Confidence
        ↓
11. Why-Not-Yet + Opportunity Window
        ↓
12. 30–60 天付费 Pilot
        ↓
13. 为什么客户会继续付钱？
        ↓
14. 怎么从卖时间变成拥有资产？
        ↓
15. Real Option：加码 / 等待 / 放弃
        ↓
16. Decision Ledger：后来现实同不同意？
```

这不是一张“因素清单”，而是一条**逐层排除伪机会的因果链**。前面某个关键环节断掉，后面再漂亮也救不了。

| 环节 | 通俗问题 | 为什么必须看 |
|---|---|---|
| 结构性需求 | 就算今天这个技术没了，人还想要这个结果吗？ | 防止拿着技术找需求。 |
| 结构变化 | 为什么以前不行、现在突然行了？ | 有需求不等于有新机会。 |
| 职场→创业迁移 | 哪些岗位已经在偷偷积累客户、交易、供应商、信任和隐性知识？ | 有些职业离第一笔自己的收入天然更近。 |
| 领先信号 | 行为、招聘预算、供应商活动正在往哪里移动？ | 财报通常太晚。 |
| 真实付款 | 谁从什么预算里拿真钱出来？ | 流量、融资、下载量都可能很高，但没有付款就还不是生意。 |
| 产业形成 | 是否出现岗位、供应商、标准、认证、服务商？ | 一个爆品不等于一个产业。 |
| 经济质量 | 毛利、复购、CAC、现金流站得住吗？ | 防止把投流、补贴、GMV 和故事误判成好生意。 |
| Power Pool | 行业最后谁有资格把利润留下来？ | 创造价值的人未必拿走利润。 |
| 个人适配 | 为什么是你？你比普通外行多什么？ | 95 分的行业，对你可能只有 30 分。 |
| 证据置信 | 重要证据到底看到了多少？质量怎么样？ | 防止一个精确分数制造虚假确定性。 |
| Why-Not-Yet / Window | 既然这么好，为什么别人没做完？窗口还剩多久？ | 专门消灭隐藏结构性障碍和已经在关闭的机会。 |
| 付费 Pilot | 能不能 30–60 天让真实客户用真钱投票？ | 用小实验替代大赌注。 |
| 复购 | 第二个月为什么还付？ | 第一单不是商业模式。 |
| 资产化 | 创始人停工 30 天，公司还剩什么值钱的？ | 区分高薪自雇和真正所有权。 |
| Real Option | 什么证据出现才继续加码？什么事实出现必须认错？ | 控制下注大小。 |
| Decision Ledger | 当初的判断后来经得起现实吗？ | 防止事后重写历史。 |

完整推导见：[`references/reasoning-chain.md`](references/reasoning-chain.md)

# Career-to-Founder Transition Lens｜职场 → 创业迁移透镜

核心问题不是：

> 谁职位最高？谁学历最好？

而是：

> **哪些职业本身，就在长期积累一门生意需要的原材料？**

判断标准包括：

```text
离交易近
+ 离付款人近
+ 高频客户痛点
+ 供应商与渠道
+ 隐性知识
+ 信任与信誉
+ 低成本试错
+ 可合法、合规地带走的能力
+ 可资产化路径
```

值得优先研究的迁移原型包括：

1. **产业 B2B 销售 / 渠道经理**：天天接触付款人、预算、反对意见和复购周期。
2. **外贸销售 / 跨境运营 / 采购型出海人才**：同时接触产品、供应商、贸易流程和海外客户。
3. **工业售后 / 维修 / 自动化 / 工艺技术人员**：天天看到故障、停机、维修经济和真实现场瓶颈。
4. **采购 / 供应链 / 品质人才**：掌握供应商地图、价格、交付、质量和产品化机会。
5. **懂具体业务流程、又会 AI 的行业操盘手**：原本多人交付的工作可能被压缩成小团队服务。
6. **增长 / 内容 / 商业化运营人才**：离获客、转化、渠道和收入更近。

详见：[`references/career-to-founder-transition.md`](references/career-to-founder-transition.md)

# 为什么它比一般“行业分析框架”多走了几步？

这里不宣称 SWOT、PESTEL、波特五力、Lean Startup、JTBD 等框架过时。它们各自非常有价值。

Opportunity Radar 的区别，是把原本分开的层串成一个完整下注链条：

```text
宏观变化
→ 产业证据
→ 哪类职业最接近机会
→ 谁真正付款
→ 谁掌握利润
→ 这个具体的人能不能进去
→ 证据够不够支持这次下注
→ 机会窗口是不是还开着
→ 怎么用最小成本测试
→ 为什么会复购
→ 怎么形成资产
→ 什么情况下继续 / 停止
→ 以后回来检查判断对不对
```

更准确的定位是：

> **大多数经典框架擅长分析某一层；Opportunity Radar 试图把“变化 → 证据 → 职业 Edge → 付款 → 权力 → 置信 → 时机 → 实验 → 所有权”连接成一次可证伪的创业决策。**

详细比较见：[`references/framework-comparison.md`](references/framework-comparison.md)

# Score ≠ Confidence｜分数不等于把握

v8.1 新增了独立的证据层。

一个机会可以“看起来很好”，同时“证据很不完整”。

以后推荐这样输出：

```text
Signal Confirmation Score   76/100
Mobility Opportunity Score  84/100
Evidence Coverage           61%
Confidence                  Medium
Weakest Link                尚未看到复购
Key Unknown                 Pilot 后预算是否继续
```

必须明确区分：

```text
Opportunity Score
≠ Evidence Coverage
≠ Evidence Quality
≠ Confidence
```

如果分数很高但 Evidence Coverage 很低，正确动作通常不是 `START`，而是：

> **BUY A SMALL REAL OPTION：花最小代价把最关键的未知变成证据。**

详见：[`references/evidence-confidence.md`](references/evidence-confidence.md)

# Why-Not-Yet + Opportunity Window

任何“看起来特别好的机会”，都必须回答两个尖锐问题：

> **既然这么好，为什么别人还没有把它做完？**

以及：

> **这个不对称进入窗口还能开多久？**

窗口分成：

```text
Opening
→ Expanding
→ Crowding
→ Consolidating
→ Closed to generalists
```

框架必须主动寻找最强的反方解释，例如：客户其实不愿付钱、集成成本高于价值、销售周期太长、责任风险太高、平台会免费打包、供给极易扩张、Power Pool 根本不在你这里。

详见：[`references/window-and-why-not-yet.md`](references/window-and-why-not-yet.md)

# 两套评分，而不是一个总分

## Signal Confirmation Score

回答：

> **这个机会到底是真的，还是大家在讲故事？**

看付款、留存、招聘、供应链、资本质量、制度化、扩散和持续时间。

## Mobility Opportunity Score

回答：

> **即使这个行业是真的，它是不是适合这个具体的人？**

看职业 Edge、客户入口、启动成本、首笔现金速度、杠杆、资产化、Power Pool 接近度、竞争与监管。

```text
好行业 ≠ 好公司 ≠ 好投资 ≠ 适合你的创业机会
```

见：[`references/scorecards.md`](references/scorecards.md)

# 创业书只推荐 3 本

1. **《The Mom Test》— Rob Fitzpatrick**：防止把礼貌赞美当成真实需求。
2. **《The Lean Startup》— Eric Ries**：把创业假设变成便宜、快速的学习循环。
3. **《7 Powers》— Hamilton Helmer**：理解一个已经能卖的生意，如何建立长期经济权力。

```text
Customer Truth → Validated Learning → Durable Power
真实需求 → 低成本验证 → 持久优势
```

为什么偏偏是这三本，见：[`references/recommended-reading.md`](references/recommended-reading.md)

# Skill 最终必须输出什么？

一次完整分析应该得到：

1. Operator Advantage / 创业者原型；
2. 职场 → 创业迁移评估；
3. 结构性需求 + 为什么是现在；
4. 产业阶段 + 有日期的证据；
5. Signal Radar，并说明**为什么每个信号重要**；
6. 3–7 个具体生意，而不是模糊行业名；
7. User / Beneficiary / Buyer / Payer；
8. 双评分；
9. Evidence Coverage + Confidence + Key Unknowns；
10. Power Pool 与利润捕获逻辑；
11. Why-Not-Yet + Opportunity Window；
12. 单位经济 + 第一单设计；
13. 复购机制；
14. 资产化路径；
15. Leading / Confirmation / Kill Criteria；
16. Weakest Link；
17. 最终结论：**START / BUY A REAL OPTION / WATCH / REJECT**。

# 设计原则

- **Evidence before narrative**：故事不是证据。
- **Payment before popularity**：流行不等于付款。
- **Career edge before prestige**：职位光环不等于创业优势。
- **Score ≠ Probability**：分数不是成功概率，必须同时报告 Coverage 和 Confidence。
- **Power before TAM worship**：大市场不等于你能赚到钱。
- **Window before urgency theater**：窗口变窄不能把坏机会变成好机会。
- **Pilot before product**：先买信息，再重投入。
- **Recurrence before scale**：第一单不是商业模式。
- **Assetization before vanity growth**：目标是所有权，不是更忙的工作。
- **Kill criteria before conviction**：一个好假说必须允许自己被杀死。
- **Backtest before boasting**：不要围绕赢家重写历史。
- **Ledger before hindsight**：保留旧判断，允许现实打脸。
- **Synthetic public examples only**：公开仓库绝不使用私人用户信息做案例。

## 一句话

> **Opportunity Radar 寻找结构变化，识别最靠近变化的职业与操作者，衡量证据和窗口，验证真钱与利润归属，再把判断变成最低成本的付费实验，最终指向 Owned Capital，并把原始判断留下来接受未来现实检验。**
