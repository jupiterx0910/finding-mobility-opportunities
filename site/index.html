HOW WE THINK / 02

从产业变化，到一笔真实订单

行业增长不等于创业机会。我们沿着一条可以被证伪的推理链，逐层检查利润是否存在、能否进入、是否能留下。

01 / CHANGE

识别结构变化

技术成本、制度、供给、渠道或客户行为发生了什么变化？为什么是现在？

02 / PAYER

找到真正付款者

谁有预算？购买什么结果？现有替代方案的成本和痛点是什么？

03 / POWER

判断利润归属

谁有定价权、客户关系、数据、渠道或交付壁垒？新进入者能留下什么？

04 / TEST

设计低成本验证

用访谈、报价、付费试单和复购数据检验关键假设，而不是先写商业计划。

RESEARCH INTEGRITY / 03

让判断有证据，也允许判断被推翻

A

事实 ≠ 推断 ≠ 假设

每条核心判断都应标明证据类型、来源与未知项。

B

资本热度 ≠ 客户需求

融资和媒体关注只能提供信号，不能替代付款、留存与单位经济。

C

高分 ≠ 高置信

关键证据缺失时，正确动作可能是小额验证，而非重仓进入。

D

保留历史判断

新证据可以改变结论，但不能静默改写过去的判断。

THE REAL QUESTION

不是“哪个行业会火”，
而是 “利润会流向哪里，我能从哪里进入？”
